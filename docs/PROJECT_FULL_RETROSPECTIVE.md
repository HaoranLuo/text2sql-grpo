## 一、阶段一：起跑与三连败（2026-08 上旬）

### 1.1 起步
- 目标：Qwen2.5-Coder-3B 在 Spider 官方 test-suite 上拿高分（CCF-B 投稿为目标）。
- 第一代：API 蒸馏 SFT（DeepSeek 老师讲义 + 质量过滤 + 15% gold 直喂）。
- 三代递进：v1 60.8 → v2 63.5 → v3 63.6。**63.6 即饱和**（蒸馏剂量-反应曲线顶）。

### 1.2 GRPO 三连败
- 三种奖励配方（binary / three_level / partial）各试一次，全部 ≈ 0 提升。
- 根因（事后确认）：模型已背熟训练集（train 上奖励均值 0.98±0.02，见外部负结果仓库 jenishk20 印证）——**强 SFT 起点 + 执行奖励 GRPO 无增益**是可重复的现象。
- 这是我们第一次踩进"模型见过训练集"的坑，后来催生了三级防污染检验。

### 1.3 导师的 1000 步收敛实验（3b_1000st）
- 配方：3B + three_level 奖励 GRPO，Spider 1000 题训练子集，1000 步，每 25 步存档。
- 成绩（1000 题子集口径）：基线 52.4 → 25 步 53.5 → **50 步 53.9（峰值）** → 75 步 53.0 → 终模 53.0。
- 训练曲线实证（200 条日志）：奖励均值全程 0.366（始终远高于 0.1 partial 线）；**KL 散度 0.000238→0.000691，2.91 倍单调上涨无饱和**；梯度均值 0.069、860 步单尖峰 0.218 自动恢复。
- **结论：50 步即收敛，后 950 步为无效漂移**（累积奖励线性但成绩平台）。
- 口径警告：1000 题子集偏难，与全量 1034 题差约 -7.4pp（`docs/l7_material_inventory.md` F5 条目）。
- 报告：`docs/EXPERIMENT_1000ST_ANALYSIS.md`（画图修复说明：主曲线曾误用 ckpt-75 日志只画 75 步，已修复重画）。

### 1.4 阶段遗产
- 三代 SFT checkpoint（v1/v2/v3）+ GRPO 老模型（p2a_500）——后来多源池的全部原料。
- 教训一：训练侧涨分到头了；教训二：模型见过训练集会毁掉评估与 RL 信号。

## 二、阶段二：换思路——执行分组投票（8 月中旬）

### 2.1 核心想法
一个学生不可靠，那就让 4 个 checkpoint 各采样 16 次（64 候选/题），用一个聪明规则挑最优。

### 2.2 MI-VAV 执行分组
- 把每题 64 份候选在官方 test-suite 的**全部数据库副本**（每题 25-60 个）上各跑一遍；**所有副本结果完全一致**才归一组（跨实例执行等值组）；跳过空组/全零组；人多的组胜出。
- 这与 Spider 官方评测语义天然同构（官方也是按多副本执行对）。
- 成绩：**74.3%**（多源池）/ 74.8%（纯未见池）。
- 参照：同期复现 FINER 论文方法，官方口径 76.6%（其论文口径宣称 85.0）——确立了"我们自己的数字只信官方 test-suite"的口径铁律。

### 2.3 资产
- `src/adjudicate_pool.py`：执行分组 + 官方执行判定的核心引擎（53 条单测）。
- 候选池 `outputs/eval_pool_multi/items.json` / `outputs/eval_pool_unseen/items.json`——后续所有实验都复用这份"生成一次、实验 N 次"的资产。

## 三、阶段三：最大突破——ORM 判卷老师（8 月中下旬）

### 3.1 方法
- 训练一个 3B 生成式 Yes/No 判卷器（ORM）：用 `P(Yes) = sigmoid(logit_Yes - logit_No)` 校准打分。
- 训练数据：20,415 条候选（自动打标：执行结果 vs 金标准），LoRA r32/α64，2-5 小时 A40。
- 终裁规则：**组人数 × 判卷 P(Yes)**，取最大（grouphead）。

### 3.2 成绩
- 多源池：74.3 → **86.1%**（+11.8pp）
- 纯未见池：74.8 → **83.4%**（+8.6pp，干净头条=论文主表数字）
- 难度拆解（多源池）：easy 95.2 / medium 89.7 / hard 82.8 / extra 66.3——**难题涨得最凶**（hard +23pp、extra +24pp）。

### 3.3 三级防污染检验（全项目最值钱的方法学遗产）
为防止"判卷老师背答案"假象，做了三层验证：
| 检验 | 数字 | 结论 |
|---|---|---|
| 同池考试（判卷见过训练题） | 86.7 | 疑似背题 |
| 同门新题（v3 候选，未训过） | 82.4 | 有真本事但有亲缘红利 |
| 异血统题（p2a_500 候选） | 78.4（同池基线 67.7） | **铁证：判卷是真能力** |
| 纯未见池（v3+p2a_500） | **83.4** | 论文最终引用 |

### 3.4 资产与天花板
- 判卷 checkpoint `checkpoints/orm_b1`；候选池（含血统标记）→ 消融实验用。
- 错误预算分解：池上限 **89.4%** = 180 道选择错误 + 103 道生成错误。
- 报告：`docs/MI_VAV_METHOD.md`、`docs/SELECTION_V2_PLAN.md`。

## 四、阶段四：三张"白捡牌"全落空（8 月下旬）

文献指出的三个低成本改进，逐一实验全部失败：

### 4.1 判卷均衡重训（P1-1）
- 教材正负比从 34% 调到 60:40（bal2 配方），重训判卷：dev 排序能力 **+3.9pp**（78.4→82.4）。
- 官方成绩：**不涨**（多源池 86.1 → 85.4，未见池 83.6 → 83.6）。
- **关键发现：瓶颈不在判卷排序能力，在候选池天花板**（即便判卷再聪明，池里没有更好答案）。

### 4.2 M8 采样平均（P1-2）
- 按 MARS-SQL 思路对判卷采样 8 次取平均：官方 -1.5 / -0.6。
- 诊断：dev 上 tie_frac 0.96——判卷对"近邻答案"的排序本来就近似随机，采样噪声放大了这种随机性。

### 4.3 CAPS 级联（P1-3）
- 先用"部分 SQL 证据"粗筛、再精判：-3.1 ~ 0。
- 诊断：部分证据与全文打分仅弱相关（Spearman 0.51）、token 只省 2%——级联反而更贵。

### 4.4 消融表（正结果，论文核心证据）
把 4 源拆开单独/组合测：
- 判卷增益：所有子集 +7~12pp
- 多源收益：**双源即饱和**（单源 83.0-83.8 → 双源 86.2 → 四源 86.1）

### 4.5 阶段结论
融合层（grouphead）已近似最优；**剩余全部杠杆在候选池质量**（生成侧）。报告：`docs/SELECTION_V2_PLAN.md`、IMPROVEMENT_DEEP_DIVE.md、消融结果见 records。

## 五、阶段五：错误注入 CPT——失败但守住底线（8 月下旬）

### 5.1 实验
按 RetrySQL 论文配方教模型自纠错：`{错步}[BACK]{正确步}` 数据 + 全参 CPT（LoRA 学不会，论文实证）。
- 10,616 条损坏数据（FS 未来步、p=0.2），A40 330 步，3.3 小时健康收敛。

### 5.2 GO/NO-GO 门（论文方法学贡献）
预注册判定：训练中途 ckpt-100 和终模单次 Spider dev 官方 EX 若掉超过基线 0.5pp 即禁入池。
- 基线 63.5 → ckpt-100 60.8 → 终模 57.8。**NO-GO，拦住了劣化模型进池。**
- 诚实教训：RetrySQL 配方在它自己的设置（1.5B base、BIRD、特殊 token 格式）有效，在我们（强 SFT Instruct、chat 格式、Spider）上**有害**——自纠错训练不是普适配方。
- 报告：监管 agent 复盘 + records 记录。

### 5.3 阶段结论
训练侧到此收官：所有可行配方（SFT/RL/CPT）都试过，天花板明确。

## 六、阶段六：BIRD 战役——跨基准验证与适配（8 月 21 日至今）

BIRD 是 2024-2026 年 Text-to-SQL 的默认国际基准（数据库大且脏、题目要数值常识、官方提供 evidence），我们必须回答"方法跨基准还行不行"。

### 6.1 数据与口径
- dev.json：1534 题、11 库；金标准 dev.sql 与官方评估器（FINER 仓库内置 `evaluation_bird_ex.py`，与官方 100% 一致）。
- 生成：4 源 × 16 采样 × 1534 题 = **98,176 候选**，单引擎 4×LoRA 分 5 切片跑完（3090，~4h）。

### 6.2 裸考与三级检验的跨基准重演
- MI-VAV：**56.26**（simple 64.65 / mod 45.26 / chall 37.93）
- Spider 判卷直接上场：**52.54**（-3.72pp，比 MI-VAV 还差）——**判卷老师跨基准"认生"**，与三级检验方法学一致：判卷泛化有血统边界。
- 免费投票天花板（论文对照）：纯字面投票 40.81 / 字面相似金标准 51.04——我们的训练判卷即便域外也已经**超过免费把戏的天花板**。

### 6.3 判卷便宜适配（本场最大胜利）
- 做法：BIRD 候选自动打标（语义与官方评估器逐字对齐：行序无关、重复行折叠、列序敏感；gold 失败题剔除）+ cap12 均衡 + LoRA 1 epoch，A40 ~4.75h。
- 结果：**56.26 → 60.37**（+4.11pp），难度三列全线上涨；McNemar fixed79/broken16，双侧 p=6.8e-12。
- 预注册判定（冻结于 docs/BIRD_JUDGE_ADAPTATION_PLAN.md）：>56.26 成功、≥58.26 强、双侧 p<0.01——**全部达成，STRONG SUCCESS**。
- 协议披露（监管 agent 发现并登记）：实测正率 18.75% <20% → 冻结决策表的主配方应为 bird_raw（自动加权版）；bird_raw 补跑已在路上（当前 A40 训练中）。
- 方法学结论：**判卷跨基准失效可被几小时便宜适配修复**——验证器路线的可迁移性证据，论文亮点。

### 6.4 表结构检索器（生成侧杠杆）
- LitE-SQL 式 0.6B 嵌入检索器：BIRD 召回@3 **89.1%**、Spider 99.1%；微调 2.5h 后**与基座持平**（基座已饱和）——价值转向精确率 P@3（55.7%）用于 prompt 裁剪（只喂相关表）。
- 状态：训练完成，推理接入待排。

### 6.5 自动证据（负结果，方向性线索）
- 规则版自动证据（库摘要+样例行+关键词，复刻 SEED 规则思路）替换官方 evidence：**显著负**（证据池 vav 41.98 vs 56.26，-14.28pp，p=1.97e-34）。
- 逐题归因：1386 题"替换式"失败（值接地错、关键语义被稀释、列错位）；**148 题官方缺失时"从无到有" +1.35pp**（噪声级但方向对）。
- 教训：SEED 文献 +17.7pp 用的是 LLM 生成版，规则版不是等价物；论文中如实记录尝试与失败模式。
- 状态：已归档；混合策略（仅官方缺失题注入）待试。

### 6.6 金标准审计（论文的诚实性背书）
- 1534 题全量执行：仅 2 题超时（结果正确），0 空结果——**新版 BIRD dev 可执行性 99.87%**。
- 60 题人工抽样：8.3% 强可疑标注（过滤粒度、排序方向、任意行选择、限定词缺失四类模式），13 题复核清单已列——论文里可引用以说明"评估噪声下限"。

### 6.7 当前在跑
- bird_raw 主配方补跑（A40）——预注册决策表要求的对照，今晚出分。
- 证据混合策略生成（待 GPU 空闲）——唯一被证据战役证明有方向性的子方案。
