## 一、实验背景与目的

- 来源：导师要求的**1000 步收敛实验**（贡献清单第 6 条「3b_1000st 1000 步收敛实验（提交与补评作业）」）。
- 目的：回答「三级奖励 GRPO 在 3B 模型上多久收敛、多训练是否还有增益」，产出一组训练曲线图与阶段成绩表。
- 设置：3B 基座 + three_level 奖励（binary/partial/atomic 三级），Spider **1000 条**训练数据，训练 **1000 步**；每 25 步存检查点，选基线/25/50/75/最终五档，在 **1000 题评测子集**上测匹配率。
- 对照：与更早的 **100 条**小规模实验（same 奖励，100 题口径）对比——`compare_100_vs_1000.png`。

> ⚠️ **口径警告**：1000 题评测子集**偏难**（与全量 1034 题口径差约 −7.4pp，见 `docs/l7_material_inventory.md` F5 条目：`3b_1000_checkpoint-50` 53.9% 对应全量口径 46.5% 量级）。**本报告所有百分比为 1000 题子集口径，禁止与全量 1034 题官方口径数字直接混比。**

## 二、训练曲线：逐面板实证描述

数据取自 `trainer_state_1000steps.json`（200 条记录，步长 5→1000）。

### 2.1 奖励均值（四面板左上 / 六面板左上）

| 阶段 | 平均奖励 |
|---|---|
| 0–100 步 | 0.3366 |
| 100–300 步 | 0.3525 |
| 300–600 步 | 0.3654 |
| 600–1000 步 | 0.3811 |
| 全程 | 0.3662（min 0.170 / max 0.671，单步数据） |

- **第一性事实**：奖励均值全程稳定在 0.34~0.38，远高于黄色虚线 **0.1（partial 奖励及格线）**——模型学会了拿到分数级奖励，且从未回落。
- **第二性事实**：分阶段均值是**缓慢爬升**的（0.337→0.381，+13% 相对提升），但曲线视觉上呈锯齿平台——爬升藏在噪声里（±1 std 阴影带宽约 0.2~0.8），每步波动远大于阶段间涨幅。
- 图上 y 轴范围 0~0.8，均值带中点约在中下部；蓝色带状阴影始终覆盖 0.1 黄线之上。
- **解读**：学习在头几十步完成 80%，此后 900 步仅有缓增，属于「边际收益递减」的典型形态。

### 2.2 奖励标准差（右上）

- 数值范围 **0.05~0.31**，中位约 0.18；无明显漂移趋势，振荡贯穿全程。
- 含义：批内组间奖励有区分度（>0），但波动大；GRPO 的组内 advantage 归一化依赖 std，std 大则组内相对差被压低——是「信号存在但噪声大」的量化证据。

### 2.3 梯度范数（左下）

- 全程均值 **0.0686**，绝大多数点落在 0.04~0.12 窄带；**唯一尖峰：第 860 步，0.218**（约为均值的 3.2 倍，单发，前 10 步恢复）。
- 解读：训练稳定性良好，无梯度爆炸；860 步尖峰为孤立事件（对应训练数据某批次异常，未见成绩副作用——ckpt-75 与 final 成绩一致 53.0）。

### 2.4 KL 散度（右下，全文最重要）

| 阶段末 | KL 值 |
|---|---|
| 第 5 步 | 0.000238 |
| 第 100 步 | 0.000318 |
| 第 300 步 | 0.000352 |
| 第 600 步 | 0.000543 |
| 第 1000 步 | 0.000691 |
| **全程倍数** | **2.91×** |

- 曲线**单调上升贯穿 1000 步，无饱和迹象**（600→1000 加速段斜率更陡）。
- 含义（三层）：
  (a) 模型策略从未稳定，一直在「改变自己」；
  (b) 改变的速率与收益无关——奖励平台期里 KL 仍在膨胀；
  (c) 这是**过训练/无效漂移**的教科书信号：策略距离拉大但没有换来任务奖励，且后半段斜率变陡，继续训练存在偏离奖励优化目标的累积风险。

### 2.5 累积奖励（六面板上中）

- 从 0 严格线性爬至 **73.247**（200 点平均每步 +0.366，与 2.1 均值完全自洽）。
- 线性 = 每步平均奖励恒定：没有发散、没有衰减、没有二次加速——「稳态训练」的视觉证据，但与「成绩平台」叠加后，其真正含义是**稳态地停留在同一水平**，而非稳态地进步。

### 2.6 生成长度（六面板右下）——数据缺失，如实标注

- 图上黄线恒为 **0**，远低于 512 上限虚线 —— 初看可疑。
- 实证检查：`log_history` 中 `completion_length` 字段 **200/200 条全部为 None**（非零记录数 = 0）。**结论：该面板为日志缺字段的绘图假象，不能解读为「生成长度 0」**。若要真实生成长度轨迹，需重跑训练并开启该字段（当前不计划重跑，标注为已知局限）。

## 三、阶段成绩快照（1000 题子集口径，已逐文件核验）

| 阶段 | Parse 率 | 执行成功率 | 匹配率 |
|---|---|---|---|
| 基线（0 步） | 99.5% | 82.7% | **52.4%** |
| ckpt-25 | 99.3% | 83.0% | **53.5%** |
| **ckpt-50（峰值）** | 99.3% | 81.3% | **53.9%** |
| ckpt-75 | 99.7% | 81.9% | **53.0%** |
| final（1000 步） | 99.7% | 81.9% | **53.0%** |

- 解析率 99.3~99.7%（执行失败率 17~19% 为该子集正常水平，与解析率无关）。
- 匹配率轨迹：52.4 → 53.5 → **53.9** → 53.0 → 53.0。
- **峰值出现在第 50 步**（+1.5pp vs 基线）；其后 150 步回吐 0.9pp，750~950 步完全持平。
- 补充：图 `compare_100_vs_1000.png` 中 100 题实验对应 `[45.0, 50.0, 34.0, 36.0, 36.0]`（脚本内硬编码值，源自当日 100 题评测记录，未单独立档，引用时按「当时记录」标注）。

## 四、核心结论（可直接用于给导师/论文）

1. **该配方约 50 步即收敛**：成绩在 ckpt-50 达到峰值（53.9%），后续 950 步无增益甚至微降（final 53.0%）。
2. **1000 步的后 90% 是无效漂移**：任务奖励平台（线性累积 + 阶段均值缓增 13%）与 KL 持续膨胀（2.91×，无饱和）叠加，证明后期训练只有策略偏离、没有性能收益；KL 加速段（600 步后）提示继续训练风险上升。
3. **训练稳定性良好**：梯度范数均值 0.069、唯一尖峰 860 步（0.218）自动恢复；无梯度爆炸/奖励发散。
4. **期望管理**：本实验口径为偏难 1000 题子集；与全量 1034 题官方口径差约 −7.4pp，引用数字时必须注明取样子集，避免与主实验数字混比。
